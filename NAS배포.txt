NAS에 올려서 쓰는 방법

※ 지금 권장 방식은 개인 클라우드(Streamlit Cloud)입니다. → CLOUD배포.txt 를 보세요.
※ 아래는 NAS Docker가 필요할 때만 사용합니다.

이 폴더(nas_upload)를 통째로 NAS에 복사하고, 아래 방법 중 하나로 "한 번만" 켜면 됩니다.
설정 파일을 고칠 필요는 없습니다. 켜진 뒤에는 다른 PC에서 브라우저로 접속만 하면 됩니다.

  접속 주소: http://NAS아이피:8501


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 1) 시놀로지 Container Manager (마우스로만, 권장)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. File Station에서 docker 공유 폴더 안에 이 폴더를 복사
     예: /docker/work-worksheet
  2. 패키지 센터 → Container Manager 설치 (이미 있으면 생략)
  3. Container Manager → 프로젝트 → 생성
       - 프로젝트 이름: work-worksheet
       - 경로: 1에서 복사한 폴더 선택
       - "기존 docker-compose.yml 사용" 선택 → 다음 → 완료
  4. 처음 한 번은 설치에 몇 분 걸립니다. 상태가 "실행 중"이 되면 끝.
  5. 다른 PC 브라우저에서 http://NAS아이피:8501

  NAS를 껐다 켜도 자동으로 다시 켜집니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
방법 2) 명령 한 줄 (SSH 접속 가능한 NAS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  cd /volume1/docker/work-worksheet
  sudo sh nas_start.sh

  - Docker가 있으면 Docker로, 없으면 Python으로 알아서 켭니다.
  - 창을 닫아도 계속 켜져 있습니다.
  - 끄기: sudo sh nas_stop.sh
  - 파일을 새로 올린 뒤 다시 실행하면 최신 버전으로 켜집니다.
  - Python 방식은 NAS 재부팅 후 자동으로 켜지지 않습니다.
    작업 스케줄러 → 부팅 시 → "sh /volume1/docker/work-worksheet/nas_start.sh" 등록

직원 PC에서 쓰는 법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - 설치 없음
  - 가장 편한 방법: 작업지도서_열기.html 을 더블클릭
      (처음 한 번만 NAS 주소 입력 → 다음부터는 바로 열림)
      바탕화면이나 공유 폴더에 두고 쓰세요
  - 또는 Chrome/Edge에서 http://NAS아이피:8501
  - 사진 올리기 → PPT 만들기 → PPT 받기


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
안 될 때
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ★ "사이트에 연결할 수 없음" / ERR_CONNECTION_REFUSED
      → HTML 문제가 아닙니다. NAS에서 앱(컨테이너)이 꺼져 있습니다.
      → Container Manager → work-worksheet → 「시작」
      → 또는 SSH: cd /volume1/docker/work-worksheet && sudo sh nas_start.sh
      → 상태가 "실행 중"이 된 뒤 http://NAS아이피:8501 다시 접속

  - 접속이 안 됨: NAS 방화벽에서 8501 포트 허용
  - 8501을 이미 다른 프로그램이 씀:
      docker-compose.yml 의 "8501:8501" 앞 숫자만 바꾸기 (예: "8601:8501")
      → 주소도 http://NAS아이피:8601
  - 오래된 32비트 ARM NAS는 설치가 실패할 수 있습니다. (x86/64비트 NAS 권장)
  - 폴더만 공유(탐색기)해서는 동작하지 않습니다. 위 방법으로 켜야 합니다.
  - 작업지도서_열기.html 은 "문"일 뿐입니다. 앱을 켜 주는 파일이 아닙니다.


폴더 안 파일 설명 (지우지 마세요)
  SERVER_MODE      서버용 표시 파일
  output/          만든 PPT 저장
  saved_layouts/   저장한 칸 배치
